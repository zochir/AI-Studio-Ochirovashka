# AI Comic Studio — мобильная сборка

**Разработчики: Очир Зулаев и Алиса**

AI Comic Studio — Android-приложение для подготовки сценария и раскадровки комиксов, подключения генератора изображений и экспорта страницы в SVG.

## Как получить APK

1. Откройте вкладку [Actions](https://github.com/zochir/AI-Studio-Ochirovashka/actions).
2. Выберите последний успешный запуск **Mobile APK build (no emulator dependency)**.
3. В разделе Artifacts скачайте **AI-Studio-Ochirovashka-APK**.
4. Распакуйте ZIP и установите APK на Android. При необходимости разрешите установку из используемого источника.

Это debug-сборка для тестирования, а не подписанный релиз Google Play.

## Что доступно

- Локальная текстовая раскадровка без платного API.
- Подключение совместимого Chat Completions API для сценария.
- Подключение совместимого Images API для генерации иллюстраций.
- Интеграция с ComfyUI через API workflow JSON.
- Сохранение проекта в локальном хранилище WebView.
- Экспорт раскадровки в SVG.

## Важные ограничения

- **Текстовая раскадровка не генерирует рисунки сама по себе.** Для иллюстраций необходим совместимый сервис изображений или работающий ComfyUI с загруженной моделью и API workflow.
- ComfyUI должен быть доступен с устройства; для подключения по локальной сети телефон и компьютер обычно должны находиться в одной сети. WebView/CORS может блокировать прямые запросы — в таком случае нужен корректно настроенный серверный прокси или приложение с безопасным нативным сетевым слоем.
- Само приложение не включает крупную диффузионную модель, поэтому полностью автономная генерация изображений на телефоне пока не реализована.
- Совместимость API, расходы провайдера и доступность моделей зависят от выбранного сервиса. Использование облачного API может быть платным.
- Не вводите секретные ключи в сборку, которую собираетесь распространять. В текущем прототипе ключи вводятся в интерфейс и используются клиентом; для публичного коммерческого приложения нужен серверный прокси с управлением секретами, ограничением запросов и защитой от злоупотреблений.
- Коммерческое использование моделей и зависимостей требует отдельной проверки их лицензий.

## Проверки CI

GitHub Actions проверяет JavaScript, базовые сценарии редактора и Comic Studio с **имитированными ответами API**, затем собирает APK и проверяет архив. Отдельная проверка в Android-эмуляторе пытается установить и запустить приложение. Успех mock-тестов не подтверждает реальную генерацию изображений, а успешная сборка сама по себе не заменяет проверку запуска на устройстве.

## Сборка

Автоматическая сборка запускается workflow **Mobile APK build (no emulator dependency)**. APK и файл контрольной суммы доступны как артефакты успешного запуска в GitHub Actions.
